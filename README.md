# Nmap Technical Deep-Dive & Network Enumeration

## 📖 Overview
This repository contains an in-depth technical report detailing the practical application of Nmap (Network Mapper). The project focuses on the methodology of network discovery, identifying open ports, and understanding the nuances of different scanning flags.

## 🛠️ Technical Content
* **Scanning Methodologies:** Detailed breakdown of TCP and UDP scanning techniques.
* **Host Discovery:** Techniques for identifying active devices within a network range.
* **Service & OS Fingerprinting:** Using Nmap to identify running services, versions, and operating systems.
* **Command Implementation:** A guide to essential and advanced Nmap flags used during the assessment.
* **Output Analysis:** Interpreting results to identify a target's attack surface.
